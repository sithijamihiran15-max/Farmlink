FARMLINK - QUICK START (WINDOWS PATH BUG FIXED)

WINDOWS
1. Extract the ZIP completely using Extract All.
2. Open the extracted FarmLink folder.
3. Double-click run.bat. Do NOT run the .bat inside the ZIP.
4. Wait for "Compiled 24 Java source files successfully."
5. Open the localhost URL printed in the terminal, usually http://127.0.0.1:8080/
   or http://127.0.0.1:8081/ if port 8080 is occupied.
6. Keep the terminal window open while using the website.

MAC / LINUX
1. Extract the ZIP completely.
2. Open Terminal in the FarmLink folder.
3. Run: bash run.sh
4. Open the localhost URL printed in the terminal.

SYSTEM REQUIREMENTS
- Full JDK 17+ (java -version AND javac -version must both work).
- No Maven, MySQL, or Node.js required. HSQLDB is bundled.
- Run the server before using the browser; don't double-click web/index.html.
- Demo farmer: DEMOFARMER / farmer1234
- Demo buyer: DEMOBUYER / buyer1234
- If you see a different error, copy the exact console message.

WHAT WAS FIXED
Previous run.bat wrote Windows source paths with backslashes to a javac @file.
The compiler interpreted backslashes as escapes and reported "Invalid filename".
This version uses CompileProject.java and the standard Java Compiler API to
compile source files as Path objects. This handles Windows drive-letter paths
and spaces in folder names without javac argument-file escaping problems.
