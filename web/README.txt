FARMLINK — EDITABLE LIVE FRONTEND
=================================

These are the original 21 HTML screen filenames, kept editable and enhanced
with css/responsive-fixes.css and js/app.js for the Java backend.

Run bash ../run.sh on macOS/Linux or ../run.bat on Windows, then open
http://127.0.0.1:8080/. Do not open files with file://; the live frontend
needs the Java REST API and embedded database.

Customize HTML here; change css/style.css, css/static.css and
css/responsive-fixes.css for styles, or js/app.js for interactive behavior.
The untouched original UI is in ../original-ui/.

Read ../README.md and ../docs/IMPLEMENTATION_GUIDE.md for full instructions.
