FARMLINK WINDOWS COMPILATION ERROR - REPAIRED

Original error:
  error: Invalid filename: L:FarmLink_Fixed_Start_ProjectFarmLinksrcmainjavacom...Account.java

Cause: The previous run.bat generated a javac @argument file containing
Windows backslash paths. Javac interprets backslashes as escape sequences,
corrupting the filenames.

Fix: The new run.bat starts CompileProject.java, which uses the JDK Compiler
API and passes Java source files as Path objects, with no @argument file.

To run:
1. Extract the entire ZIP (do not open run.bat inside the ZIP preview).
2. Enter the extracted FarmLink folder.
3. Double-click run.bat.
4. Wait for "Compiled 24 Java source files successfully."
5. Open the localhost URL shown in that window. Keep the window open.

To fix an existing copy instead of downloading the full ZIP, replace BOTH
run.bat and CompileProject.java with the files in the small patch ZIP.

Requires JDK 17 or higher. The HTML, CSS, database, and existing
application Java files have not been changed.
