FARMLINK — STANDALONE HTML + CSS UI SCREENS
============================================

WHAT IS INSIDE
- 21 separate HTML files (including pages.html for a visual index).
- css/style.css: shared base layout and Figma-inspired visual design.
- css/static.css: extra navigation rules to work without JavaScript.
- assets/*.svg: local illustrative artwork and site icon.

HOW TO OPEN
Open pages.html (page index) or index.html (homepage) directly in Chrome/Edge.
You can also use VS Code's Live Server extension.
No npm, Node.js, database, JavaScript, or backend is needed to view these templates.

FOR YOUR JAVA OOP CAMPUS PROJECT
These are presentation-only templates. They do not log in, create accounts,
submit forms, filter products, save favourites, post gigs, send messages,
or update orders. Actions are UI placeholders, and dashboard data is sample data.
Your teammates can implement those operations using Java OOP (for example,
Java classes + Servlets/JSP or Spring Boot controllers, with a database),
then connect form action/method attributes and server-side dynamic values.

IMPORTANT FOR TEAMMATES
- Replace sample user, crop, and request content with data from Java backend.
- Handle form validation and input security on the server; HTML is not sufficient.
- Wire forms and buttons to Java controllers or change HTML into JSP templates.
- Static CSS navigation on mobile uses <details>, no scripts.
- No payment, identity verification, or real-order functionality is implemented.
- Visual assets are local illustrative SVG files, not exact photos from Figma.
