FARMLINK + MYSQL — WINDOWS SETUP
================================

You have already created farmlink_db and farmlink_app. Next:

1. In MySQL Workbench (administrator connection), open database/mysql_schema.sql
   and click the lightning bolt (Execute All). It creates all 6 tables.
   Execute: USE farmlink_db; SHOW TABLES;
   You should see users, harvests, inquiries, messages, saved, sessions.

2. Download the official MySQL Connector/J .jar from:
   https://dev.mysql.com/downloads/connector/j/
   Unzip the driver download if needed and copy the mysql-connector-j-*.jar
   into THIS PROJECT's lib folder, alongside hsqldb.jar.
   Do not rename it or put it inside src/main/java.

3. Open a NEW Windows Command Prompt inside the extracted FarmLink folder.
   (In File Explorer's address bar, type cmd and press Enter.)
   Do NOT put these commands inside MySQL Workbench.

4. In Command Prompt (replace MyRealPassword with YOUR password):
   set "FARMLINK_DB=mysql"
   set "FARMLINK_DB_USER=farmlink_app"
   set "FARMLINK_DB_PASSWORD=MyRealPassword"
   run.bat

5. Open the http://127.0.0.1:8080/ or :8081/ address shown by the server.
   The terminal should print 'Database: MySQL'.

6. Register a TEST account or post a TEST harvest on the website.
   Then refresh in MySQL Workbench and execute:
     USE farmlink_db;
     SELECT id, role, first_name, nic FROM users ORDER BY id DESC;
     SELECT id, title, quantity FROM harvests ORDER BY id DESC;
   The test data should now be visible in Workbench.

7. When finished, stop the website with Ctrl+C.

COMMON ERRORS:
- MySQL password is missing: set FARMLINK_DB_PASSWORD first.
- MySQL Connector/J .jar is missing: download JDBC driver and copy to lib/.
- Access denied for user: check MySQL password, GRANT permissions, and host.
- Communications link failure: start MySQL Server, check port 3306.
- Table doesn't exist: import database/mysql_schema.sql using admin Workbench.
- If you double-click run.bat without setting env vars in that process,
  it uses HSQLDB. Use the SAME Command Prompt for set commands and run.bat.

BACKUP: No old HSQLDB rows are copied automatically! Make a backup of data/.
You can return to HSQLDB by closing this terminal and double-clicking run.bat.
Do not send your MySQL password in screenshots or chats.
